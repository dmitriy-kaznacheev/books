1. Суть предложения
Временно перевести Техсхему из НИОКР в режим технической поддержки.

2. Причина
Большой объём работ по адаптации системы под Linux: система уже собрана, но требует доработок по ошибкам и нюансам эксплуатации, выявляемым пользователями.

Модернизация расчётного ядра — требуется адаптация ключевых модулей («Групповой контроль», «Карта прогнозных дебитов», «Характеристики вытеснения», «Гистерезис ОФП и капиллярных сил») к обновлённым интерфейсам.

Модуль «Экономика» написан на старой платформе, несовместимой с Linux — нужна отдельная проработка.

Кадровая ситуация: вакансии открыты, поиск ведётся через все доступные каналы, но специалистов с одновременным знанием предметной области (нефтяное моделирование) и стека C++/Qt/Linux на рынке практически нет.

В текущих условиях мы не тянем одновременно и техническую доработку, и развитие нового функционала.

3. Чем будем заниматься в рамках техподдержки
Поддержка пользователей (консультирование, помощь в эксплуатации, оперативное реагирование).

Обеспечение стабильности системы (мониторинг, устранение сбоев).

Доработка и исправление ошибок по обращениям пользователей (включая ошибки при работе в Linux).

Адаптация модулей к обновлённому расчётному ядру (перечислены).

Адаптация модуля «Экономика» для работы в Linux.

Без разработки нового функционала.

4. Прогноз и условия возврата к НИОКР
Возврат к полноценному НИОКР планируем в 2028 году при выполнении следующих условий:

завершение адаптации всех модулей под Linux и новое ядро;

восстановление штатной численности до 14 человек;

закрытие текущего беклога по ошибкам пользователей.

В первую очередь после возврата — моделирование ХМУНов.
