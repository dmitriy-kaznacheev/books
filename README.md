СЛАЙД 5. Автокорреляция
СЛАЙД

Заголовок: Автокорреляция скважин: исследование алгоритмов ML

Плашка: прототип, в стабильной версии нет, следующий год.

Эволюция подходов: динамическое программирование → детекция долин → Витерби/Дейкстра → DTW → улучшенный DTW.

Цифры: >2 м снижение средней ошибки, 0,7 м — медиана ошибки.

Рисунок 149 «Корреляция 823-826», рисунок 150 «Корреляция 823-826 в ПО "Геосхема"», рисунок 151 «Корреляция маркеров».

ДОКЛАД
Отдельное направление — исследование алгоритмов машинного обучения для задач нашей отрасли. В качестве полигона взята задача автоматической корреляции скважин.

Шли последовательно. Сначала попробовали классические подходы — динамическое программирование, детекцию долин по матрице Гессе (способ найти на планшете корреляции протяжённые участки, где значения меняются слабее всего, — то есть наиболее вероятные линии сопоставления), алгоритмы Витерби и Дейкстры. Это известные методы поиска оптимального пути. Они давали результат, но недостаточно точный на сложных участках — при выклиниваниях и больших интервалах без данных.

Потом перешли к динамическому выравниванию последовательностей — DTW — и его улучшенной версии. DTW не сравнивает точки с одинаковыми номерами — он выстраивает соответствие между кривыми по форме: один участок одной кривой может соответствовать нескольким точкам другой. Это важно, когда пласт в одной скважине мощнее, чем в другой: участок на глубине 100 м в первой скважине может соответствовать участку на 110 м во второй, и DTW это находит. Улучшение в том, что сравнение идёт по аналитическим сигналам (представление кривой двумя компонентами: сама кривая и её фаза через преобразование Гильберта). Преобразование Гильберта — математический приём, который по кривой строит её вторую компоненту — фазу колебаний; вместе они дают аналитический сигнал: и значение, и положение внутри волны. Так мы сравниваем форму и фазу колебаний, а не абсолютные значения — поэтому соответствие находится устойчивее, даже если кривые слегка сдвинуты или растянуты по глубине. Плюс мера сходства semblance (числовая оценка от 0 до 1: насколько два участка кривых похожи по форме и фазе; 1 — полное совпадение, 0 — различия) и два механизма для снижения числа ложных соответствий. Первый — многовариантный расчёт: один и тот же результат считается несколько раз с разными настройками, и выбирается наиболее согласованное решение — если результат устойчив к настройкам, ему можно доверять. Второй — диагностика неоднозначных результатов: алгоритм сам помечает маркеры, где он не уверен — низкое сходство, нет данных, сильная зависимость от настроек, — и такие маркеры идут интерпретатору на проверку, а не выдаются как готовый прогноз.

Результаты на прототипах обнадёживающие: по сравнению с ранними подходами средняя ошибка снизилась более чем на 2 метра, медиана ошибки на размеченных данных — 0,7 метра. При этом подчеркну: это исследовательская работа. В стабильной версии «Геосхемы» этой функциональности пока нет — продолжаем в следующем году.

Характеристики вытеснения.

ДОКЛАД
Продолжу по алгоритмам ядра.

Несоседние соединения ячеек. Реализована автоматическая генерация NNC (когда между двумя проницаемыми ячейками есть непроницаемая прослойка, NNC позволяет учесть переток через неё) по критической толщине и градиенту давления, с корректной обработкой областей измельчения сетки — LGR (область сетки с измельчением: ячейки там мельче, чтобы точнее описать призабойную зону) и нормировкой проводимости: для несоседних ячеек нет общей грани, поэтому площадь контакта и расстояние приводятся к корректным значениям с учётом геометрии и измельчения.

Выравнивание дебитов — максимальные дебиты принудительно выравниваются под единое граничное значение, без учёта весов. Расчёт работает в многопоточном режиме через MPI — с синхронизацией данных коллективной операцией, что исключает гонки данных.

Характеристики вытеснения. Исправлен алгоритм расчёта, переработан интерфейс, устранены аварийные завершения.
