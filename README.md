В течение 2026 года выполнялась разработка ПО «Геосхема» в соответствии с пожеланиями пользователей, предоставлялись консультации по работе с геологическими и геонавигационными модулями, формированию проектов и импорту данных. Работы выполнялись по нескольким направлениям: развитие дерева данных проекта, модулей «Схема корреляции», «Разрез», «Макет» и «Карта», создание системы контекстной справки, реализация карточки скважины и редакторов данных, автоматизация сборки и развертывания, развитие модуля «Workflow», перевод модулей метаинформации и «Создание проекта из Реестра» на таблицу метаданных проекта, адаптация импорта из БД «ГеоПро» после миграции на PostgreSQL, актуализация плагинов Petrel, развитие модуля «Геонавигация», адаптация ПО под ОС «Альт Рабочая станция», внедрение сетевого менеджера лицензий, доработка калькуляторов контуров и поверхностей, тестирование алгоритмов расчёта 3D-кубов с использованием трендов, а также исследование и прототипирование алгоритмов автоматической корреляции скважин.
