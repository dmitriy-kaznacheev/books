1. Суть предложения
Временно перевести Техсхему из НИОКР в режим технической поддержки.

2. Причина
Большой объём работ по адаптации системы под Linux (система уже собрана, но требует доработок по выявляемым ошибкам и нюансам эксплуатации).

Модернизация расчётного ядра – изменения внутренних интерфейсов, требуется адаптация прикладных модулей для работы с обновлённой версией.

Модуль «Экономика» написан на старой платформе, несовместимой с Linux – нужна отдельная проработка.

Кадровая ситуация: программистов найти трудно, а специалистов с опытом в предметной области (нефтяное моделирование) и нужными технологиями – ещё сложнее. Вакансии открыты, поиск идёт, закрыть не удаётся.

В текущих условиях не тянем одновременно и техническую доработку, и развитие нового функционала.

3. Чем будем заниматься в рамках техподдержки
Поддержка пользователей (консультирование, помощь в эксплуатации, оперативное реагирование на запросы).

Обеспечение стабильности системы (мониторинг, устранение сбоев, бесперебойная работа).

Доработка и исправление ошибок по обращениям пользователей (включая ошибки при работе в Linux).

Адаптация модулей к обновлённому расчётному ядру:

«Групповой контроль»,

«Карта прогнозных дебитов»,

«Характеристики вытеснения»,

«Гистерезис ОФП и капиллярных сил».

Адаптация модуля «Экономика» для работы в Linux.

Без разработки нового функционала.

4. Прогноз на будущее
После завершения технических работ по адаптации и восстановления штата – возврат к НИОКР по Техсхеме планируем в 2028 году.

Первая задача – моделирование ХМУНов.
