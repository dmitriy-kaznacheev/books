На выходных запустил вашу модель по описанному сценарию: пересчёт с t₀, изменение только перфорации в 2033 году.

Результат: закачка с 2026 по 2033 год отличается в среднем на 0.006%, максимально — до 0.05%. Исторический период совпадает точно.

На истории отклонений нет, потому что закачка там задана жёстко (замеры) и не пересчитывается — симулятор использует её как входной параметр. В прогнозе закачка — результат расчёта: на каждом шаге решается нелинейная система, и из-за операций с плавающей точкой накапливается небольшая погрешность округления. При параллельных вычислениях порядок операций может немного отличаться от запуска к запуску, что тоже даёт вклад.

Ориентиры по допустимым отклонениям при пересчёте с теми же входными данными:

0.001–0.01% — норма для большинства моделей (ваш средний результат попадает сюда).

0.01–0.05% — приемлемо для крупных моделей (миллионы ячеек) со стандартными допусками.

0.05–0.1% — верхняя граница допустимого для очень крупных моделей.

0.1% и выше — повод проверить настройки сходимости солвера.

Таким образом, расчётное ядро работает корректно. Если в вашем случае отклонения значительно больше — причина в изменении входных данных при пересборке модели (статика, PVT, ОФП, контакты). Рекомендую проверить их на момент двух запусков.
