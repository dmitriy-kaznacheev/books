Геологическое моделирование в структурных подразделениях ПАО «Сургутнефтегаз» выполняется с использованием импортного программного обеспечения (ПО) «Petrel» и «RMS», а также ПО «Изолайн». Для геонавигационного сопровождения бурения горизонтальных скважин в реальном времени в компании используется отечественное ПО «СтарСтир» (ООО «РОДЖИИ Европа»). Разработка собственного ПО для геологического моделирования позволяет снизить зависимость от импортного ПО, сократить затраты на закупку и сопровождение стороннего ПО и адаптировать возможности собственного ПО под цели и задачи сотрудников ПАО «Сургутнефтегаз». Разрабатываемое в рамках выполнения темы ПО «Геосхема» тестируется и внедряется для решения производственных задач в структурных подразделениях ПАО «Сургутнефтегаз». На данный момент количество активных пользователей ПО «Геосхема» в НГДУ, ЦГСД, тресте «Сургутнефтегеофизика» и в Тюменском отделении «СургутНИПИнефть» – [указать число].

В течение 2026 года выполнялась разработка новых и доработка существующих модулей в ПО «Геосхема». Работы выполнялись в соответствии с техническим заданием и пожеланиями пользователей, предоставлялись консультации по выполнению подсчета запасов, формированию схем корреляции, построению геологических разрезов, оформлению и построению карт, работе с таблицами атрибутов, выполнению импорта данных из корпоративных баз данных, подготовке макетов к печати, выполнению работ по геологическому сопровождению бурения.

Расширены функциональные возможности модулей импорта и экспорта данных в проект, включая плагины для «Petrel» (актуализация для версий 2016–2021, доработка экспорта геометрии модели и кубов параметров, переработан механизм подключения подпроекта SimboLibs). Завершён переход клиентской части ПО на взаимодействие с БД «ГеоПро» на СУБД PostgreSQL с загрузкой всех типов данных, включая ГИС (через сервисы), ПГИ (через БД «f2») и описание керна (через сервис «coreservice»). В модуле «Операции с данными» расширены возможности калькуляторов контуров и поверхностей, реализованы алгоритмы сглаживания конвергентной интерполяции (сплайны, NURBS, CLSPIA) и прототип работы с разломами. Доработан модуль «Геонавигация» для сопровождения бурения скважин: реализован математический аппарат инверсии сопротивления (прямая и обратная задачи), добавлен режим «Режим сопротивлений», доработаны векторы бурения, подписи и легенды макета, реализовано взаимодействие с модулем «Макет». Модуль «Макет» расширен новыми элементами и операциями, реализована трехуровневая иерархия заголовков легенды и поддержка формата EMF на Linux. Произведены доработки в модуле «Карта»: реализован тайлинг растровых изображений большого размера, ускорен алгоритм отрисовки изолиний, добавлена валидация контуров при построении разломов, реализованы комментарии к элементам карты, новая функция добавления точек пересечения контуров, модернизирован редактор разреза. В целях решения задач трехмерного геологического моделирования проведено тестирование и оптимизация алгоритмов расчёта 3D-кубов с использованием 1D-, 2D- и 3D-трендов, выполнен сравнительный анализ с ПО «Petrel». Проведена исследовательская работа и реализованы прототипы алгоритмов автоматической корреляции скважин: рассмотрен планшет Жековского, классические варианты решения (Витерби, Дейкстра/A*, волновой алгоритм Ли), методы машинного обучения (CV/DP, Fast Marching, HVD), реализован новый подход на основе DTW и IDTW.

Произведены общие доработки в программном обеспечении: реализованы архитектурные изменения дерева данных проекта (перенос дерева ГИС в общий модуль), создана система контекстной справки (Context-Sensitive Help) на базе модуля HelpManager, реализована «Карточка скважины» с мгновенной реакцией на изменение данных, доработаны редакторы РИГИС и комментариев, автоматизирована сборка и развертывание средствами CMake (включая сборку RPM-пакета для ОС «Альт Рабочая станция»), реализована концепция выходных контейнеров в модуле «Workflow», модули метаинформации и «Создание проекта из Реестра» переведены на работу с таблицей метаданных проекта. Выполнена адаптация ПО для работы под ОС «Альт Рабочая станция», произведён переход на Qt 5.14.2. Разработан и внедрён сетевой менеджер лицензий, начата опытно-промышленная эксплуатация сервера лицензий с ПО «Геосхема».

Так как ПО «Геосхема» – собственная разработка ПАО «Сургутнефтегаз», количество лицензий не ограничено. Это позволяет эффективно использовать его для анализа и визуализации различной геолого-геофизической информации, оперативного построения геологических карт, просмотра трехмерных геолого-гидродинамических моделей. Закупка соответствующего количества лицензий сторонних производителей, в том числе иностранных, экономически нецелесообразна ввиду их высокой стоимости.
