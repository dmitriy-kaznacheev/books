Реализован прототип прямого моделирования — многопластовый, для произвольного стека пластов; на выходе — синтетический отклик прибора.

На основе прямого расчёта решается обратная задача — подбор параметров модели под реальный каротаж. Реализован прототип двуслойной инверсии, проверенный на синтетических данных. Многопластовая инверсия — в разработке: реализован интерфейс, в планах на следующий год.
