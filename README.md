Текст доклада: «Отдельный блок — общие доработки. Здесь много небольших, но важных изменений, которые формируют удобство ежедневной работы.

Дерево данных. Дерево ГИС раньше жило в отдельном модуле — мы перенесли его в общий, и теперь работа с данными проекта унифицирована; это также создаёт основу для добавления ПГИ в ядро „Геосхемы". Для дерева ГИС стал доступен виджет поиска. В меню „Объединение контуров" при количестве объединений больше десяти отображаются первые десять и пункт „все…", открывающий окно с иерархией и поиском по названию. В дереве данных добавлена возможность создания контрольных точек.

«Схема корреляции». Для масштаба 1/500 реализована шкала 5 метров — раньше автоматика разряжала сетку до 25 метров, теперь шкала работает как надо. В выпадающем списке шаблонов появились ползунки прокрутки и зона растягивания: шаблонов стало много, и они не помещались. В редакторе профиля добавлен режим работы с группами скважин — группу можно перетащить целиком, дубликаты не добавятся. Механизм „Заполнить группу по условию" теперь позволяет сохранять, изменять и удалять настройки поиска: при открытии окна подгружаются последние настройки для этой группы.

«Разрез». На перфорации доработано отображение SSTVD и MD: MD всегда в положительной области, SSTVD — по настройкам. Скважины, не участвующие в построении пластов и пропластков, теперь видно сразу — цвет иконки, курсив, подсказка. Реализовано отображение РИГИС на треке скважины: секторы и текст по центру, согласованные с углом наклона ствола. Отрисовка каротажа перенесена в четыре отдельных класса — дискретные и непрерывные ГИС и РИГИС: код стал проще для доработок.

«Справка». Создана система контекстной справки. Пользователь нажимает F1 — модуль HelpManager определяет, с каким элементом он работает, и открывает нужную страницу. Соответствия хранятся не в коде, а во внешнем файле-реестре: чтобы подключить справку к новому элементу, достаточно добавить запись и написать страницу — программист не нужен. Справка упакована в единый QCH-архив.

«Макет». Переработан код отображения легенды: текст разбивается на строки по словам с учётом ширины прямоугольника. Режим „Размер по содержимому" автоматически уменьшает габариты элемента. Для управления элементами добавлены кнопки центровки с учётом точки привязки.

Карточка скважины и редакторы. Добавлены карточка скважины — всплывающее окно со сводкой и мгновенной реакцией на изменения; столбцы „Кровля SSTVD" и „Подошва SSTVD" в редакторе РИГИС; контекстное меню в редакторе комментариев с копированием, вставкой и удалением по логу. Подробности по каждому пункту — в резерве».
