Результатом выполнения темы [номер темы] является разработка программного обеспечения «Геосхема» и доработка его функциональных возможностей. В рамках данной темы осуществлялась поддержка пользователей – специалистов Тюменского отделения «СургутНИПИнефть» и других структурных подразделений ПАО «Сургутнефтегаз».

В течение 2026 года выполнялась разработка ПО «Геосхема» в соответствии с пожеланиями пользователей, предоставлялись консультации по работе с геологическими и геонавигационными модулями, формированию проектов и импорту данных. Работы выполнялись по нескольким направлениям: развитие дерева данных проекта и модуля «Схема корреляции», доработка модуля «Разрез» и отображения данных РИГИС, создание системы контекстной справки, модернизация модуля «Макет», реализация карточки скважины и редакторов РИГИС и комментариев, автоматизация сборки и развертывания средствами CMake, развитие модуля «Workflow», перевод модулей метаинформации и «Создание проекта из Реестра» на работу с таблицей метаданных проекта, адаптация импорта из БД «ГеоПро» после миграции на PostgreSQL, актуализация плагинов Petrel, доработка модуля «Карта» (тайлинг, изолинии, разломы, примыкание и редактирование контуров, редактор разреза), развитие модуля «Геонавигация» (математический аппарат инверсии сопротивления, режим сопротивлений, векторы бурения, подписи и легенды макета), адаптация ПО для работы под ОС «Альт Рабочая станция», внедрение сетевого менеджера лицензий, разработка алгоритмов сглаживания конвергентной интерполяции (сплайны, NURBS, CLSPIA) и работы с разломами, доработка калькуляторов контуров и поверхностей, тестирование алгоритмов расчёта 3D-кубов с использованием 1D-, 2D- и 3D-трендов, а также исследование и прототипирование алгоритмов автоматической корреляции скважин.

Произведены архитектурные изменения дерева данных проекта: дерево ГИС структурно отделено от прочих деревьев и интегрировано в общий модуль, что обеспечило унификацию работы с данными проекта, доступ к виджету поиска и создало основу для дальнейшего добавления сущности ПГИ в ядро ПО «Геосхема». Изменена логика отображения списка объединений контуров, реализованы иерархическое представление и поиск по названию. В дереве данных добавлена возможность создания контрольных точек.

В модуле «Схема корреляции» реализована шкала глубин 5 м для вертикального масштаба «1/500», доработан выпадающий список выбора шаблонов для скважин, реализована работа с группами скважин в редакторе корреляционного профиля с синхронизацией режимов и проверкой на дубликаты, расширен функционал механизма «Заполнить группу по условию» с возможностью сохранения, изменения и удаления настроек поиска.

В модуле «Разрез» доработано отображение «SSTVD» и «MD» на перфорации, изменено отображение не участвующих в построении разреза скважин, реализована возможность отображения значений РИГИС на треке скважины с согласованием секторов и текста углу наклона ствола, проведён рефакторинг кода с выделением отдельных классов для рисования кривых.

Создана комплексная система помощи пользователю (Context-Sensitive Help) на базе модуля HelpManager: реализованы перехват нажатия F1, многоуровневый алгоритм поиска страницы справки, хранение соответствий во внешнем файле-реестре, поддержка справочного архива в формате .qch, класс HelpBrowser для отображения страниц с ресурсами, асинхронный полнотекстовый поиск и динамические «хлебные крошки». Внедрение системы позволило связать программу с её документацией и обеспечить параллельную работу разработчиков и писателей документации.

В модуле «Макет» переработан код отображения легенды классификации с переносом строк, доработан режим «Размер по содержимому», реализован механизм управления элементами макета с кнопками центровки и учётом точки привязки, исправлена отрисовка перфораций и синхронизация состояния кубов.

Реализована «Карточка скважины» с краткой информацией о скважине и мгновенной реакцией на изменение данных в других модулях. В редакторе РИГИС добавлены нередактируемые столбцы «Кровля SSTVD» и «Подошва SSTVD». В редакторе комментариев реализовано контекстное меню с копированием представления и данных, вставкой из буфера обмена и удалением комментариев текущего лога.

Автоматизирована сборка пакетов для развертывания ПО «Геосхема» на ОС Windows с применением CMake и QtIFW, реализованы компоненты установщика, устранены конфликты между бета- и релизной версиями, сборка инсталляторов переведена в режим «offline only».

В модуле «Workflow» реализована концепция выходных контейнеров, графический интерфейс для входных и выходных контейнеров, а также прототип менеджера задач. Модули метаинформации и «Создание проекта из Реестра» переведены на работу с таблицей метаданных проекта в базе данных SQLite, реализован скрипт переноса метаданных из JSON-файла, обеспечена возможность редактирования метаданных через внешний вызов.

Завершён переход клиентской части ПО «Геосхема» на взаимодействие с БД «ГеоПро» на СУБД PostgreSQL: реализована загрузка всех типов данных (скважины, траектории, атрибуты, РИГИС, ГИС, маркеры, перфорации, история добычи, ПГИ, описание керна, контуры), загрузка ГИС переведена на сервисы, загрузка ПГИ — на БД «f2» с сопоставлением словарей из «ГеоПро», загрузка керна — через сервис «coreservice».

Продолжена актуализация плагинов Petrel для версий 2016–2021: доработан экспорт геометрии модели и кубов параметров с проверкой объёма данных, доработан интерфейс вкладки «Скважины», учтено изменение перечня сохраняемых данных для маркеров. Переработан механизм подключения подпроекта SimboLibs через обертку SimboLibsWrapper, что упрощает обновление версий и не требует адаптации исходного кода SimboLibs.

В модуле «Карта» реализована функция «Показать в дереве», переработана система оповещений между модулями, реализован механизм перемещения объектов и папок между картами, доработан алгоритм удаления объектов, реализована отрисовка растровых изображений большого размера при помощи тайлинга, ускорен алгоритм рисования изолиний, добавлена валидация контуров при построении разломов, реализованы комментарии к элементам карты, новый параметр примыкания контуров, функция добавления точек пересечения контуров, модернизирован редактор разреза с динамическим формированием списка скважин и двухвариантным расчётом отклонения, переработан интерфейс вставки уровней, реализована настройка минимального масштаба карты.

В модуле «Геонавигация» исследован и реализован математический аппарат инверсии сопротивления, разделённый на физико-математическое, стыковочное и управляющее ядра; реализованы прямая задача (алгоритм Чоу) и обратная задача (двухслойная инверсия) с юнит-тестами и python-планшетом для визуализации; добавлен режим «Режим сопротивлений» с тремя вариантами расчёта; реализовано взаимодействие с модулем «Макет», доработаны векторы бурения с возможностью экспорта в проект, реализована трехуровневая иерархия заголовков легенды макета.

Проведена адаптация ПО «Геосхема» для работы на ОС «Альт Рабочая станция»: исправлены платформенно-зависимые ошибки, адаптированы механизмы восстановления проекта и проверки прав записи, выполнена сборка RPM-пакета с использованием CPack, реализована проверка обновлений уведомительного характера. Произведён переход на Qt 5.14.2 с пересборкой сторонних библиотек и обновлением клиента Oracle до версии 12.2. Реализована поддержка формата EMF на Linux с применением библиотеки libqemf.

Разработан и внедрён сетевой менеджер лицензий, обеспечивающий контроль и ограничение доступа к программному обеспечению компании. Начата опытно-промышленная эксплуатация сервера лицензий с ПО «Геосхема» в режиме «пропуск ошибок», реализованы режимы лицензирования на клиенте и прототип поведения программы при потере лицензии.

В модуле «Операции с данными» разработаны и протестированы методы сглаживания поверхности после расчёта точек «конвергентным методом»: рассмотрены сплайны, B-Spline, NURBS, реализована ограниченная задача наименьших квадратов на основе CLSPIA, предложен альтернативный многоуровневый подход с прогнозом по производным и сглаживанием кривизны. Реализован прототип собственного алгоритма работы с разломами, задающими геометрический барьер для численных связей.

Доработан калькулятор контуров: скорректированы точки примыкания, реализована работа с функциями библиотеки boost с подготовкой входных данных, проведена оптимизация функций пересечения, объединения и отсечения контуров, добавлена операция «Замкнуть контуры», реализовано копирование атрибутов, операция «Создать зоны около точек» дополнена возможностью учёта значения атрибута. В калькуляторах поверхностей исправлена некорректная запись данных, добавлена валидация входных контуров, реализован пункт «Слой в поверхность», добавлена обработка зенитных углов в фильтрах по траекториям, реализовано добавление точек на линии триангуляции, добавлены ограничения расчёта поверхности по контуру.

Проведено тестирование алгоритмов расчёта 3D-кубов с использованием 1D-, 2D- и 3D-трендов, выполнена оптимизация алгоритмов применения трендов, проведён сравнительный анализ алгоритма применения 2D-тренда при моделировании непрерывных кубов свойств с ПО «Petrel», по результатам которого внесены корректировки в функцию согласования сетки тренда и куба.

Реализованы прототипы алгоритмов автоматической корреляции скважин: рассмотрен планшет Жековского, классические варианты решения (Витерби, Дейкстра/A*, волновой алгоритм Ли), методы машинного обучения (CV/DP, Fast Marching, HVD), реализован новый подход на основе DTW и IDTW с робастной нормировкой, аналитическими сигналами, многовариантным расчётом и выбором согласованного решения. Результаты тестирования показывают повышенную точность относительно предыдущего варианта; при ручном контроле промежутков корреляции алгоритм получает высокие результаты точности в предсказании маркеров.
