Почему сырой код пользователям не идет:
Наши пользователи работают с реальными проектами и у них свои жесткие сроки. Если бета падает, ломает старые расчеты или меняет API — они перестанут ей пользоваться и будут ждать релиза. Итог: ошибки всплывут только в релизе, придется фиксить аврально, накопится негатив к программе.

Что проверяем перед передачей пользователю:

Нет падений на базовых сценариях.

Нет неопределенного поведения (UB).

Нет утечек памяти.

API и прошлые расчеты стабильны (обратная совместимость).

Такой подход уже отлажен на ПрограммеБ — пользователи доверяют бете, мы ловим проблемы до релиза, а не после.
