Ориентиры по допустимым отклонениям при пересчёте с теми же входными данными:

0.001–0.01% — норма.

0.05–0.1% — приемлемо для больших моделей.

1% и выше — повод проверить настройки сходимости солвера.

Таким образом, расчётное ядро работает корректно. Если в вашем случае отклонения значительно больше — причина в изменении входных данных при пересборке модели (статика, PVT, ОФП, контакты). Рекомендую проверить их на момент двух запусков.
