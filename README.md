Поручение 3 (разовое, итоговое): Сдача наработок и месячный отчёт
Исполнитель: Кондратьев Н.Ю.

Основание: завершение отчётного периода (сентябрь 2026 г.), необходимость предоставления отчёта о выполнении задач по утверждённому плану работ (карточка Directum RX-44712909-3) и передачи наработок перед отпуском.

Содержание поручения:

В последний рабочий день перед отпуском 18.09.2026 до 15:00:

Предоставить письменный отчёт о проделанной работе за сентябрь (по установленной в отделе форме).

Лично подойти к руководителю для:

сдачи всех наработок (код, коммиты, документация, файлы конфигурации и т.п.);

Критерий приёмки итогового поручения:

Поручение считается выполненным, если:

Предоставлен письменный отчёт о проделанной работе за сентябрь по установленной форме.

Сотрудник лично явился к руководителю.

Переданы все наработки (код, коммиты, документация, файлы конфигурации и т.п.).

Даны объяснения по незакрытым задачам и действиям после отпуска.

Зафиксированы ответы на вопросы руководителя.

Срок: 18.09.2026 до 15:00.
