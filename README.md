2. Причина
Большой объём работ по адаптации системы под Linux: система уже собрана, но в процессе эксплуатации выявляются ошибки и нюансы, требующие доработки.

→ СЮДА ВСТАВИТЬ ЭТОТ АБЗАЦ (после фразы про Linux, перед модернизацией ядра):

Отдельный крупный блок — собственный сетевой сервер лицензий. Он был написан с нуля для перехода на Linux, поскольку от предыдущих разработчиков модуля лицензирования не осталось кода. Сервер должен обеспечивать прозрачное подключение пользователей к корпоративному серверу без ручного ввода лицензионных ключей. На данный момент требуется его полноценное тестирование, отлов ошибок и доводка.

Модернизация расчётного ядра — изменения внутренних интерфейсов, требуется адаптация прикладных модулей для работы с обновлённой версией.

Модуль «Экономика» написан на старой платформе, несовместимой с Linux, — нужна отдельная проработка.

Кадровая ситуация: вакансии открыты, поиск ведётся через все доступные каналы, но специалистов с одновременным знанием предметной области (нефтяное моделирование) и стека C++/Qt/Linux на рынке практически нет.

В текущих условиях мы не тянем одновременно и такой объём технических доработок, и развитие нового функционала.
